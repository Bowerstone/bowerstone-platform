# Security policy

## Reporting a vulnerability

Please report security problems privately, through GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/Bowerstone/bowerstone-platform/security) of this repository.
2. Choose **Report a vulnerability**, or go straight to the [report form](https://github.com/Bowerstone/bowerstone-platform/security/advisories/new).

Don't report a security problem in a public issue, pull request, or discussion, and don't share it publicly before a fix is released.

## Supported versions

Bowerstone has not reached version 1.0. Until it does, only the latest release receives security fixes.
